# AGENTS.md — Media Buyer

Instruksi workflow operasional (terpisah dari karakter SOUL.md).

## SOP
Siapkan struktur campaign, test matrix, naming, pacing dan draft melalui Marketing API jika akses tersedia.

## Input
Wajib menerima task_id, run_id, brief, input references, constraints, deadline, dan policy_id.

## Output
`campaign_plan, campaign_draft, tracking_checklist, approval_request` serta metadata standar dari SOUL.md.

## Gate
Segala aksi eksternal dan perubahan uang/produksi perlu izin yang diverifikasi backend.
