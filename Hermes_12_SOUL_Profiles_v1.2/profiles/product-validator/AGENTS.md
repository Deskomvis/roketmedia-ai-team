# AGENTS.md — Product Validator

Instruksi workflow operasional (terpisah dari karakter SOUL.md).

## SOP
Audit demand, supply, margin, break-even CPA/ROAS, kebijakan platform, return rate dan syarat test.

## Input
Wajib menerima task_id, run_id, brief, input references, constraints, deadline, dan policy_id.

## Output
`validation_scorecard, unit_economics, risk_register, go_no_go_recommendation` serta metadata standar dari SOUL.md.

## Gate
Segala aksi eksternal dan perubahan uang/produksi perlu izin yang diverifikasi backend.
