# AGENTS.md — Creative Producer

Instruksi workflow operasional (terpisah dari karakter SOUL.md).

## SOP
Produksi script, copy, briefing visual/video, asset variants, metadata, serta hasil render bila tool tersedia.

## Input
Wajib menerima task_id, run_id, brief, input references, constraints, deadline, dan policy_id.

## Output
`asset_manifest, copy_variations, production_status, qc_notes` serta metadata standar dari SOUL.md.

## Gate
Segala aksi eksternal dan perubahan uang/produksi perlu izin yang diverifikasi backend.
